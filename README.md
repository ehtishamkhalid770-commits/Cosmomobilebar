# Cosmo Mobile Bar — Luxury Mobile Bartending Experience

A modern, high-conversion, luxury mobile bartending web application built with React 19, TypeScript, and Tailwind CSS. Designed specifically for seamless 1:1 migration to **WordPress & Elementor**.

---

## 🍸 Key Pages & Features

1. **Home (`/`)**: High-impact Hero, Trust Strip (140+ Events, 5.0 Rating, $2M Insurance), Featured Services, Signature Cocktails Preview, and direct Booking CTAs.
2. **About Us (`/about/`)**: Founder Story (Jairo Pinto), 4 Craft Experience Pillars, Atmosphere Photo Gallery, and 5-Star Reviews.
3. **Services (`/services/`)**: 6 Event Service Cards (Weddings, Birthdays, Corporate, Anniversaries, Graduations, Private Soirées), 4-Step Process, and Venue Logistics.
4. **Cocktail Menu (`/menu/`)**: Interactive Drink Explorer with category filters (Signatures, Classics, Tropical, Mocktails), Glassware details, and Scratch Syrups standard.
5. **Packages & Pricing (`/packages/`)**: 3 Transparent Tiers (Classic Pour, Signature Cosmo, VIP Prestige), Luxury Add-ons, and full Client FAQ Accordion.
6. **Event Calculator (`/calculator/`)**: Interactive Cost Estimator, Bartender Staffing Formula, and Retail Alcohol Shopping Guide.
7. **Contact & Booking (`/contact/`)**: Event Inquiry Form with state pre-filling, Direct Phone `(240) 280-4521`, and 35-Mile DMV complimentary travel area.

## 🚀 Quick Start (Local Development)

```bash
# 1. Install dependencies
npm install

# 2. Start the Vite dev server
npm run dev

# 3. Build for production
npm run build

# 4. Preview production build
npm run preview
```

## 🛠️ WordPress & Elementor Migration Guide

This site is structured with clean, modular flex containers and standard Elementor Pro widgets:
- **Header & Navigation**: Elementor Theme Builder Header
- **Pages**: Create 7 separate pages in WordPress (`Pages → Add New`) using the *Elementor Full Width* template.
- **Forms**: WPForms, Fluent Forms, or Elementor Pro Forms.
- **Calculator**: Formidable Forms or Cost Calculator Builder.
- **Gallery**: Envira Gallery or Elementor Pro Gallery widget.
